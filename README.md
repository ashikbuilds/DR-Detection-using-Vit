# DR-Detection-using-ViT

Deep learning-based detection of diabetic retinopathy from retinal images using Transformer models with preprocessing, training, and evaluation pipeline.

---

## 📌 Overview

This project focuses on detecting **Diabetic Retinopathy (DR)** using **Vision Transformer (ViT)** models. It processes retinal fundus images and classifies them into different DR severity levels.

---

## 🚀 Features

* Image preprocessing & normalization
* Vision Transformer (ViT) based model
* Training and evaluation pipeline
* Performance metrics (Accuracy, Precision, Recall, F1-score)
* Visualization (confusion matrix, training curves)
